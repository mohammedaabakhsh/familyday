# استعادة عرض تنسيقات وجلسات — v73

طلب المالك استعادة عرض الباقات والجلسات الخارجية قبل إضافة نظام الطلب، مع الاحتفاظ بطريقة سهلة للطلب عبر واتساب. المرجع المحفوظ هو `pre-arrangements-ordering-20261125`.

تعود أقسام الصفحة الفرعية إلى التصفح على الصفحة كاملة، دون نافذة اختيار الخدمات. البطاقات المغلقة مطابقة للمرجع في المقاسات والألوان والخطوط؛ الصور والمحتويات داخل نفس السهم الأصلي. تُضاف أزرار «اطلب عبر واتساب» والمشاركة داخل التفاصيل المفتوحة، فلا تغيّر شكل القائمة المغلقة. تظل الواجهة العلوية المعتمدة والفرع والشعار محفوظة.

زر الطلب يفتح نموذجًا صغيرًا للباقة أو الجلسة وحدها، مع الكمية والاسم والكوخ ورقمه والملاحظات، ثم يجهز مسودة واتساب عبر منشئ الرسائل الأصلي ورقم المنسق الأصلي. يمكن اختيار إضافة الكيك والعصير عند طلب جلسة. طاولة الطعام تبقى خيارًا واحدًا وتُطلب بالضغط على سعر العدد والتجهيز. لا يوجد ملخص تجميعي في الصفحة الفرعية. تُحفظ الهوية وحدها؛ تبدأ الاختيارات والملاحظات من جديد لكل طلب، ولا تستعاد سلة قديمة.

يستخدم الموقع الرئيسي وضعه المضمّن السابق، وتبقى طلباته مستقلة. لم تتغير بيانات الأسعار والمحتويات والصور وأرقام الأكواخ وروابط الخدمات والباقات والجلسات أو بيانات المعاينات النصية. لا تُضاف أصول صور أو مكتبات أو منشئات رسائل مكررة.

يتعامل الإغلاق والرجوع مع نافذة الطلب دون فقد موضع التصفح أو إغلاق تفاصيل البطاقة. الروابط القديمة مثل `#package-complete` و`#session-2` تفتح القسم والبطاقة المقصودة كما كانت.

التحقق:

- `check-arrangement-orders.py`: مقارنة مقاسات البطاقات المغلقة وألوانها بالنسخة القديمة فعليًا في المتصفح، على خمس مقاسات تشمل الشاشة القصيرة؛ طلب الباقات الست والجلسات الست؛ تطابق مسودات الواتساب حرفيًا مع الأسعار الأصلية؛ المشاركة النصية بنفس الروابط؛ إضافة الكيك والعصير؛ قيد طاولة واحدة؛ الرجوع والإلغاء واسترجاع الهوية دون طلبات سابقة.
- `check-resort-native-orders.py`: استمرار الطلب المستقل في الموقع الرئيسي، مع مطابقة رسائله لطلبات البوابات، وعدم انتقال اختيارات قديمة أو تغيير روابط المشاركة.
- `check-guide-source.py`: الأقسام والصور والتفاصيل تعتمد الكتالوج المستقل، حتى عند تعطل الصفحة الرئيسية، وتتابع تغيّر بيانات المصدر.
- `check-live-cutover.py`: الروابط الأصلية والتحويلات والمعاينات والصور والطلبات المضمّنة باقية.

تُعترض جميع فتحات واتساب في الاختبارات، دون إرسال رسائل. وسم الرجوع قبل هذا التعديل `pre-arrangements-browse-restore-20261125`. الاستثناءات وبصمات الملفات في `site/cleanup-manifest.json`، والنتائج في `site/audits/arrangements-browse-v73.json`.
