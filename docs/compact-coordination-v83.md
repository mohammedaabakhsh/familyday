# بطاقات التنسيقات المختصرة — v83

طلب المالك اختصار زر الباقة إلى «اطلب هذه الباقة» في الموقع الرئيسي والفرعي، وجعل البطاقات المغلقة في الفرعي مثل صفوف الموقع الصغيرة، دون عبارة «الصور وتفاصيل الباقة».

بطاقة التنسيق المغلقة في الفرعي تعرض الاسم يمينا والسعر مع «للباقة» والسهم يسارا في صف واحد. السهم يبقى واضحا ويفتح الصور والمحتويات الأصلية كاملة. بقي لون البوابة الفاتح وتنسيق التفاصيل المفتوحة ومربع الطلب وروابط المشاركة الخاصة بكل واجهة. بطاقات الجلسات الخارجية لم تتغير.

تحقق بصري على 390 و320 و430 بكسل من صغر البطاقات الست ومواضع الاسم والسعر دون تداخل أو تمرير أفقي، وفتحها بلوحة المفاتيح، ونص الزر وفتح طلب الباقة الصحيحة والمشاركة في الواجهتين. تحقق الطلبات يؤكد نفس مسودات الباقات الست والجلسات الست والإضافة الاختيارية والطاولة الواحدة والرجوع والإلغاء، مع بقاء قياسات بطاقات الجلسات الخارجية الأصلية.

لا تغيير في الأسعار أو المحتويات أو الصور أو صانع رسالة واتساب أو متحكم مربع الطلب أو وجهات المشاركة. لم ترسل أي رسالة أثناء الفحص. مرجع العودة `pre-compact-coordination-cards-20261126`.
